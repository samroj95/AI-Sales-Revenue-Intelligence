# Installation Requirements

Two ways to run this project. **Docker (Option A) is strongly
recommended** — it avoids installing Python/Node/PostgreSQL directly on
your machine and matches exactly what CI builds and tests.

## Option A: Docker (recommended)

| Software | Required? | Version | Purpose | How to Verify |
|---|---|---|---|---|
| Docker Desktop | **Yes** | 4.30+ (includes Docker Compose v2) | Runs PostgreSQL, backend, frontend, Prometheus, Grafana as containers | `docker --version` and `docker compose version` |
| Git | **Yes** | 2.40+ | Clone/manage the repository | `git --version` |
| Visual Studio Code | Recommended, not required | latest | Editing code | `code --version` |
| A web browser | **Yes** | any modern browser | Using the frontend | n/a |

With Docker, you do **not** need Python, Node.js, or PostgreSQL
installed on Windows directly — they run inside containers.

## Option B: Running natively (no Docker)

| Software | Required? | Version | Purpose | How to Verify |
|---|---|---|---|---|
| Python | **Yes** | 3.11.x (project pins `python:3.11-slim` in Docker; 3.11 or 3.12 should both work, 3.11 is the tested target) | Backend runtime | `python --version` |
| pip | **Yes** | bundled with Python | Install Python packages | `pip --version` |
| Git | **Yes** | 2.40+ | Clone the repository | `git --version` |
| PostgreSQL | **Yes** | 16.x | Application database | `psql --version` |
| Node.js | **Yes** | 20.x LTS | Build/run the React frontend | `node --version` |
| npm | **Yes** | bundled with Node.js (10.x) | Install frontend packages | `npm --version` |
| Visual Studio Code | Recommended, not required | latest | Editing code | `code --version` |
| Docker Desktop | Not required for this path | — | — | — |

## Optional software

| Software | Required? | Purpose |
|---|---|---|
| Power BI Desktop | **No — optional.** Only needed if you want to build the Power BI report described in `powerbi/README.md`. **Power BI is NOT required to run the application** — the React frontend is the fully implemented dashboard. Windows only. | Connecting to the platform's PostgreSQL views for BI reporting |
| An LLM API key (Groq or OpenAI) | **Conditionally required.** The AI chatbot needs *one* of: a Groq API key, an OpenAI API key, or a locally running Ollama instance. Without one of these three, `/chatbot/query` and `/chat` will return a 503 error — everything else in the app works fine without it. | Powers the RAG chatbot |
| Ollama | Optional alternative to a paid API key | Fully local/free LLM backend for the chatbot (`LLM_PROVIDER=ollama` in `.env`) |

## What is explicitly NOT required

- **Visual Studio** (the full IDE) — VS Code is sufficient and is what
  this project was authored for compatibility with.
- **Anaconda/Miniconda** — plain `pip` + `venv` is all that's used; no
  conda-specific packages.
- **A cloud AWS account** — only needed if you follow
  `docs/DEPLOYMENT.md` to deploy publicly; not needed to run locally.
